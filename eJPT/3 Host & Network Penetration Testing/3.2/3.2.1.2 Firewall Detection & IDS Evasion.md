
## Firewall Detection
```
nmap -sn 10.4.27.83
nmap -Pn -sS -F 10.4.27.83
nmap -Pn -sA -p 445,3389 10.4.27.83

```
If the `STATE` in the result shows `filtered` means there is a firewall
`-sA`: To determine if ports are filtered or unfiltered by sending ACK packets

## IDS Evasion
```
nmap -Pn -sS -sV -F 10.4.27.83
nmap -Pn -sS -sV -p 80, 445, 3389-f 10.4.27.83
nmap -Pn -sS -sV -p 80, 445, 3389-f --mtu 8 10.4.27.83
```
`-Pn`: Disable host discovery (don't ping)
`-sS`: sync scan
 `-sV`: service version
 `-F`: top 100 common ports
 `-f`: fragment the packets
### Spoofing / Decoy IP
*NOTE:* Need to get connected to that network
```
nmap -Pn -sS -sV -p 445, 3389 -f --data-length 200 -D 10.10.23.1, 10.10.23.2 10.4.27.83
```
`-D`: Decoy IP flag

```
nmap -Pn -sS -sV -p 445, 3389 -f --data-length 200 -g 53 -D 10.10.23.1, 10.10.23.2 10.4.27.83
```
`-g`: Spoofing the Source Port
+
`-n`: Command can be used to disable DNS resolution in nmap
